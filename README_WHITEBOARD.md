# 出題画面の計算用ホワイトボード

## 機能

出題画面の `✏️ 計算用ホワイトボード` から、問題ごとの計算メモを開けます。

- ペン
- 消しゴム
- ペン色の変更
- 太さの変更（1〜24px）
- 描画を1手戻す
- 描画を1手進む
- 全消去
- 指・Apple Pencil・マウス入力
- 問題文・図表・選択肢の確認
- 左下の `◀ 1問戻る` / `進む ▶` から問題移動

## 操作配置

上部ツールバーは描画操作専用です。

- `↶ 描画を1手戻す`
- `↷ 描画を1手進む`
- `全消去`

問題移動は、問題確認パネルの左下にある `◀ 1問戻る` / `進む ▶` に統一しています。

## 板書の扱い

板書はサーバー、DB、端末ストレージへ保存しません。  
同じ解答中だけ問題ごとに一時保持し、問題移動で戻った場合に復元します。
