# 履歴保存方式の修正

## 修正内容

- 同じ試験回・同じ午前/午後を複数回実施しても、過去の履歴を残すように変更。
- 終了した演習は `attemptId` 付きで保存。
- Cloudflare KVでは、履歴を1つのキーに上書きせず、1回分ごとに別キーへ保存。
- 旧形式の履歴も読み込めるように互換処理を追加。
- 履歴画面で各回の正答率・所要時間・間違えた問題を確認可能。
- Cloudflare KVの「同一キーへの連続書き込み」を避けるため、途中保存のクラウド保存を軽く間引く処理を追加。

## 反映するファイル

既存プロジェクトでは、最低限以下を上書きしてください。

```text
index.html
functions/api/progress.js
```

質問データもまとめて反映する場合は、このZIP全体を既存GitHubへ上書きしてください。

## GitHub反映例

```bash
git add index.html functions/api/progress.js
git commit -m "Keep all attempt history"
git push
```

## 注意

- Cloudflare KVは強整合ではないため、保存直後に別端末や別地域から見ると反映が少し遅れることがあります。
- 途中経過の保存は「現在の状態」として上書き保存されます。
- 完了履歴は「1回ごと」に別保存されるため、同じ回を2回・3回やっても過去履歴が残ります。
