# 問題閲覧枠 調整版

## 変更内容

- 問題閲覧枠をランダム出題と同じカード型へ調整
- 試験回をプルダウン選択できるように整理
- 午前 / 午後 / 午前・午後 両方を選択可能に変更
- あとで見返すボタンを問題閲覧枠内に整理
- ログイン / 登録 横のあとで見返す重複ボタンを削除
- 回数選択後の「問題・回答を見る」は維持

## 更新ファイル

- `index.html`
- `CHANGELOG.md`
- `VERSION.json`

## 反映方法

```bash
git add index.html CHANGELOG.md VERSION.json
git commit -m "Adjust viewer panel layout"
git push
```
