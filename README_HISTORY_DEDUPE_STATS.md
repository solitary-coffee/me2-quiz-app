# 履歴重複修正 + 全体統計表示

## 修正内容

- 同じ履歴が複数表示される問題を修正しました。
- 既存の重複履歴も、表示時に `attemptId` と履歴内容の両方で重複除去します。
- 旧形式の履歴に対して、毎回ランダムな `legacy` ID が付いて重複扱いになる問題を修正しました。
- Cloudflare KV側の `/api/progress` でも重複除去を行います。
- 履歴画面の上部に全体統計を表示します。

## 表示される統計

- 通常演習回数
- 平均正答率
- 最高正答率
- 最新正答率
- 累計時間
- 平均時間
- よく間違える問題

## 反映ファイル

- `index.html`
- `functions/api/progress.js`
