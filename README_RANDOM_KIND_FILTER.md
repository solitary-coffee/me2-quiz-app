# ランダム出題：種類別フィルタ

## 追加内容

既存の6つの出題範囲に加えて、ランダム出題に `種類別に選択` を追加しました。

追加した主な種類：

- 呼吸器
- 人工心肺・ECMO
- 感染症・消毒滅菌
- 安全管理
- 血液浄化・透析
- 循環器・心電図
- 生体計測・モニタ
- 画像診断・内視鏡
- 手術室・治療機器
- 在宅・酸素療法

## JSONについて

問題JSONは変更していません。  
既存の `range`、問題文、選択肢、要点解説、選択肢解説、画像パスに含まれる語句から、ブラウザ側で種類を自動判定します。

そのため、既に編集済みの問題JSONを上書きしません。

## 判定方式

例：

```text
呼吸器 → 人工呼吸器、換気、PEEP、酸素、SpO2 など
人工心肺・ECMO → 人工心肺、ECMO、体外循環、ローラポンプ など
感染症・消毒滅菌 → 感染、滅菌、消毒薬、芽胞、標準予防策 など
安全管理 → 漏れ電流、接地、非常電源、JIS、点検 など
```

完全な問題セットが必要な場合は、後からJSON側に `kind` や `tags` を追加する方式にも拡張できます。

## 反映方法

```bash
git add index.html CHANGELOG.md VERSION.json README_RANDOM_KIND_FILTER.md
git commit -m "Add random quiz kind filters"
git push
```
