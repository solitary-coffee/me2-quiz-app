# ランダム出題機能 追加版

## 追加内容

トップ画面に「ランダム出題」を追加しました。

指定できる条件：

- 何回から何回まで
- 午前 / 午後
- 出題範囲
  - 基礎医学
  - 電気・電子・物理
  - 生体計測・画像診断
  - 医用治療機器
  - 医療安全・規格・保守管理
  - 医用材料・生体物性
  - 情報工学
  - 総合問題
- 出題数
  - 10問
  - 20問
  - 40問
  - 60問
  - 任意の問題数

## 更新ファイル

- `index.html`

## 反映方法

```bash
git add index.html
git commit -m "Add random quiz mode"
git push
```

## 補足

ランダム演習の途中保存は `random / mix` として端末キャッシュ・DB保存対象になります。
問題ごとに「第何回・午前/午後・第何問」も表示します。
