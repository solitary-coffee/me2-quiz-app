# 公式・代入式チェック追加版

## 追加内容

開発モードの文面チェックに、公式・代入式・単位のチェックを追加しました。

## 追加チェック項目

- 計算問題・公式問題の可能性があるか
- 公式が解説に記載されているか
- 代入した式・計算過程が記載されているか
- 数値に単位が付いているか
- 正答解説に公式・代入式・単位があるか
- 誤答解説で計算に触れている場合、式が不足していないか

## AI解説生成定義にも追加

計算・公式問題では以下を生成ルールに追加しています。

- 公式を必ず書く
- 代入した式を必ず書く
- 計算結果には単位を付ける
- 誤答では、公式・代入・計算・単位のどこが違うかを書く
